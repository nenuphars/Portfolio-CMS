# Portfolio CMS
Simple CMS app featuring a full frontend and backend app, automated testing and deployment

## Description

The app can be used as a portfolio or to store other kinds of text content together with images. The focus is simplicity and versatility, to make it relevant for different uses, fast and easy to use.

## Tech Stack

__Frontend:__
- Next.js
- Typescript/React

__Backend:__
- MongoDB
- ExpressJS

__Infrastructure:__
- Hetzner Cloud
- GitHub Actions
- Docker
